# Funzioni potenza

Il grafico di \(y = x^{\alpha}\) al variare dell'esponente, con la scelta dell'esponente tra molti casi tipici. Trascina i cursori, oppure premi ▶ per l'animazione. Sul grafico ti sposti trascinando con due dita (o con il mouse) e ingrandisci con Maiusc + rotellina.
