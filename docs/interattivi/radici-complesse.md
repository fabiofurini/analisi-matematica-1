# Radici n-esime complesse

Le \(n\) soluzioni di \(z^n = w\) sul piano di Gauss: scegli l'indice \(n\), il modulo e l'argomento di \(w\) e guarda i vertici del poligono regolare. Trascina i cursori, oppure premi ▶ per l'animazione. Sul grafico ti sposti trascinando con due dita (o con il mouse) e ingrandisci con Maiusc + rotellina.
