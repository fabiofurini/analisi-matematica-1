# Operazioni sui grafici

Traslazioni, dilatazioni e simmetrie di un grafico: i quattro coefficienti di \(a f(bx + c) + d\) si muovono con i cursori. Trascina i cursori, oppure premi ▶ per l'animazione. Sul grafico ti sposti trascinando con due dita (o con il mouse) e ingrandisci con Maiusc + rotellina.
